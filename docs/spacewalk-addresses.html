A Room’s addresses

A Room is what ties one conversation to the Viewers showing its 3D view. Its id is ten letters and digits, and the Worker accepts it in either case. Press New Room to open one on the chosen Deployment, the way open_viewer does, or paste an id from a Join card or from geenee.

AddressWhat it showsWho uses it
The Room link. The Viewer joins the Room, and its Room indicator says where it stands. Everyone on it is a Participant, and the camera follows whoever last took hold of it. The Organizer, from the Join card or the model, and Guests it is shared with.
Not a page: the WebSocket a Viewer opens to its Room. Refused with 403 from any origin but a Viewer’s, 426 without a WebSocket upgrade, 400 with no room. An unknown or expired Room is refused over the socket itself. The Viewer, for as long as it is open.

A Room expires after a day without use. Its Viewers are told “This Room has expired.” and let go, and what it showed is gone for good. Every tool but open_viewer then refuses the Room; open_viewer with the same room starts it over, empty.

200 The Viewer in no Room.
200 Not a Room link: the full Spacewalk app, which ignores ?room=. Only the Viewer page joins Rooms.
405 The Connector address. Hosts POST to it; a browser’s GET is refused.
403 The WebSocket address, refused to a browser tab because it is not a Viewer.
404 The Worker serves nothing else. The Viewer lives on its own host.

Tricks worth knowing


    
  
  • geenee’s Room id works here. open_viewer accepts an id it has never seen, which is how geenee opens its own Room id in Spacewalk’s Worker. An id from a geenee Card drives the same Viewer that geenee’s Workspace frames.
    • 
  
  • Only the Viewer page joins Rooms. The full app at / ignores ?room=, so a Room link must point at viewer.html. The Viewer also takes ?file=, which wins over ?room=.
    • 
  
  • ChatGPT sends no session id. Its x-openai-session header is turned into a Room id instead.
    • 
  
  • Local development runs the Worker on localhost:8787 (npm run dev:server) and the Viewer on localhost:5173 (npm run dev in the spacewalk repo). Start the Worker with --var VIEWER_URL:http://localhost:5173/viewer.html so its Room links reach the Viewer page. Secrets go in .dev.vars.
